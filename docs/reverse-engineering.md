Інші 101 інвентаризовані файли, включно з manifest JSON, залишилися поза семантичним аналізом. Парсинг усіх чотирьох успішний. Семантичне покриття часткове, досягнуто лімітів вузлів; мінімізовані/динамічні зв’язки залишаються невідомими. REA не виконував завантажені bundles під час статичного аналізу.

## Висновки

**Спостережено в UI:** публічний набір книги без входу, WPM, прогрес розділу, моноширинний текст, віртуальна клавіатура й банер про вхід для збереження прогресу. Докладні URL та налаштування — [typersguild-observations.md](typersguild-observations.md). FAQ описує Premium-імпорт EPUB/TXT; FB2 там не заявлено.

**Спостережено у завантажених скриптах; статичні факти, не runtime:**

- Ресурси розміщено під `/_next/static/chunks/`, є Turbopack bootstrap. Це ознаки поставленого Next.js/Turbopack frontend.
- У `0qa_kwzimmdy7.js` текст стану тренажера містить `currentPosition`, `formattedTargetText`, `mistakes`, `paragraphs`, а оновлення позиції обчислює індекс абзацу й позицію в ньому.
- У цьому ж модулі виклик `saveProgress` передає ідентифікатор книги, позицію, символ, індекс розділу та прапорець примусового збереження. Поруч є інвалідація запитів рекомендацій/книг у процесі читання. Реалізація сервера цим не встановлена.
- `0sm9vnc1y79s9.js` містить схему конфігурації з параметрами зупинки на помилці, регістру, акцентів, клавіатури, курсора та звуку.
- `2ntikncx_gqgk.js` містить обгортки читання localStorage/sessionStorage з обробкою відмови доступу. Наявність таких обгорток не доводить збереження повного прогресу чи книг у браузері.
- `0cugipn6dn5xv.js` містить окремі auth-gate повідомлення для збереження прогресу й завантаження книги.

**Невідомо:** серверна модель зберігання, фактична реалізація імпорту, поведінка Premium-завантаження, алгоритм обробки величезних книг і продуктивність Typersguild. У дослідженні не створювали акаунт, не оформлювали підписку, не надсилали книги й не вимірювали його import performance. Наявність DOM усього розділу не встановлює алгоритм віртуалізації.

## Реалізований результат

BookTyper незалежно відтворює основний сценарій «бібліотека → розділ → набір → наступна сесія» й додає вимоги користувача: FB2, локальні книги й прогрес без акаунта, потоковий імпорт у Web Worker, IndexedDB, обмежений фрагмент тексту та відновлення позиції.

Оформлення й програмний код BookTyper створені окремо. Bundles Typersguild не включено до готової збірки, скопійованих обкладинок і каталогу немає. Вимірювання в [verification.md](verification.md) стосуються саме BookTyper.

## Відтворення дослідження

```powershell
node tools/rea-runtime/node_modules/rea-agents/scripts/rea.mjs capture-browser-scenario docs/rea-scenario.json --format json
node scripts/collect-reference.mjs
node tools/rea-runtime/node_modules/rea-agents/scripts/rea.mjs analyze-javascript-application tools/typersguild-public --source-path 0qa_kwzimmdy7.js --source-path 0sm9vnc1y79s9.js --source-path 2ntikncx_gqgk.js --source-path 0cugipn6dn5xv.js --format json
```

Новий capture або download може стосуватися іншої версії сайту. Для повторення саме цього аналізу використовуйте збережені файли та їхні хеші, не змішуйте їх із майбутніми bundles.
