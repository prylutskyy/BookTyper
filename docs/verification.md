# Перевірка BookTyper

Дата: 2026-10-21. Windows, Node.js 24.18.0, Brave/Chromium 155.0.8059.85, headless. Усі книги в тестах синтетичні; чужі книги не завантажувалися на зовнішні сервери.

## Результати

`npm.cmd test`: **6/6**. `npm.cmd run test:browser`: **17 наскрізних сценаріїв**, без JavaScript-помилок. `npm.cmd run build`: успішно. Повний машинний звіт: [browser-report.json](browser-report.json).

Додаткова перевірка production-збірки (`node tests/production-smoke.mjs`) пройшла на власному локальному HTTP-сервері: завантаження сторінки, зібраний Worker, FB2/EPUB, реальний набір, reload, тема на мобільній ширині та повернення до початку сторінки. Зовнішні мережеві запити блокувалися; таких запитів не було. Звіт: [production-report.json](production-report.json).

Версію для GitHub Pages перевірено під адресою `http://127.0.0.1:5173/BookTyper/`: відносні шляхи JS/CSS/favicon і Worker, обидва формати книг, прогрес після reload, мобільний інтерфейс. Workflow перед публікацією повторно виконує модульні тести й production build.

## Перевірена поведінка

- Свіжа бібліотека з українською демо-книгою.
- Реальний Unicode-ввід, помилки, Backspace/Ctrl+Backspace, відновлення після reload.
- FB2-метадані, українська, emoji, виключення base64-обкладинок і приміток.
- EPUB зі стисненням, порядком spine, URL-кодуванням назв розділів, пропуском ресурсів.
- Кодування Windows-1251 та UTF-16 із BOM.
- Пошкоджений FB2: повідомлення й видалення частково записаних даних.
- Переходи до розділів, останній символ книги, повторний старт.
- Набір із дозволеними помилками, розмір тексту та збереження теми.
- Набір під час імпорту великого FB2.
- Обмежений DOM, повторне відкриття та відновлення після негайного закриття вкладки.
- Перехід між фрагментами та Backspace на їхній межі.
- Великий EPUB з одним абзацом.
- Скасування великого імпорту.
- Reload посеред імпорту й очищення незавершених даних за допомогою Web Locks.
- Експорт/відновлення резервної копії прогресу.
- Пошук і підтверджене видалення книги.
- Бібліотека й тренажер на ширині 390 px без горизонтального переповнення.

Модульні тести окремо перевіряють XML-простори імен, CDATA, сутності, пропуск скриптів, NFC на межі вхідних блоків, soft hyphen, безперервність позицій і сурогатні пари в багатомільйонному абзаці.

## Межі висновків

Це конкретні вимірювання на цьому комп’ютері. Вони не гарантують час для всіх книг чи слабших пристроїв. Не вимірювалися CPU, пікова пам’ять усього дерева процесів, час після повного перезапуску ОС, мобільне апаратне забезпечення чи всі можливі розширення EPUB. `performance.memory` стосується лише головного JS-контексту. Навмисно дуже стислий EPUB перевіряє потокове розпакування; час не можна переносити на архіви з іншою структурою.

Текст типізації зберігає позиції в UTF-16 одиницях, а користувацький ввід обробляє Unicode code points. WPM рахується як правильні натискання / 5 / активні хвилини. Паузи між вводами обмежені 10 секундами; розфокусування обнуляє відлік паузи. Статистика правильних натискань накопичувальна, включно з повторним набором після Backspace.
