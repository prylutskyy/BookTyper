# BookTyper

Локальний тренажер набору книжок, натхненний дослідженням [Typersguild](https://typersguild.com). Інтерфейс українською, без акаунта, платних обмежень і передавання імпортованих книг на сервер.

## Відкрити сайт

**[BookTyper на GitHub Pages](https://prylutskyy.github.io/BookTyper/)** — відкрийте посилання й додайте свою книгу. Встановлювати Node.js або запускати CMD для користування сайтом не потрібно. FB2/EPUB обробляються у Web Worker на вашому пристрої; GitHub Pages віддає лише статичні файли застосунку.

Книги та прогрес прив’язані до профілю браузера й адреси сайту. Дані локальної версії `127.0.0.1` автоматично не переносяться: експортуйте прогрес у налаштуваннях, імпортуйте ті самі книги на Pages і відновіть файл прогресу.

## Публікація

У репозиторії ввімкнено GitHub Pages із джерелом **GitHub Actions**. Workflow `.github/workflows/pages.yml` після push у `main` установлює залежності з lock-файла, запускає тести, збирає `dist/` і публікує його. Ручний повторний запуск доступний у вкладці Actions. Книги користувачів до репозиторію або артефактів публікації не потрапляють.

Збірка використовує відносні шляхи (`base: './'`), включно зі скриптом Worker, стилями та favicon. Її можна розмістити у підпапці `/BookTyper/` на звичайному статичному хостингу.

## Запуск у Windows

Двічі натисніть **`Start-BookTyper.cmd`** у цій папці. Він запускає локальний сервер і відкриває **http://127.0.0.1:5173** у браузері. Залиште вікно сервера відкритим; Ctrl+C зупиняє його. Після встановлення залежностей інтернет не потрібен.

Або в PowerShell:

```powershell
cd C:\Users\sashaprylutskyy\Documents\ChatGPT\BookTyper
npm.cmd start
```

Готова збірка вже міститься в `dist`. Для змін у коді: `npm.cmd run dev`. Для оновлення збірки: `npm.cmd run build`. Завжди використовуйте ту саму адресу **127.0.0.1:5173** і той самий профіль браузера: `localhost`, інший порт чи інший браузер матимуть окреме сховище.

## Можливості

- Бібліотека FB2/EPUB, пошук за назвою та автором, імпорт кількох файлів і перетягування.
- Український і багатомовний текст, UTF-8, UTF-16, Windows-1251 та інші кодування, які підтримує браузер і декларує XML. Текст нормалізується до Unicode NFC.
- EPUB читається в порядку OPF spine, а не за назвами файлів. Зображення й інші ресурси не розпаковуються. FB2-примітки та base64-зображення не потрапляють у набір.
- Набір із підсвічуванням помилок, WPM, точністю, активним часом, прогресом книги та переходом до розділів.
- Enter — новий абзац; Backspace — назад; Ctrl+Backspace — попереднє слово; Esc — пауза. Вставлення з буфера у поле набору вимкнене.
- Світла/темна тема, розмір шрифту, зупинка на помилках, спрощена пунктуація, режим фокусу, адаптивний інтерфейс.
- Автозбереження позиції й статистики; експорт/відновлення **прогресу** у JSON. Для відновлення в іншому браузері спочатку імпортуйте ті самі файли книг, потім резервну копію прогресу.
- У режимі без зупинки помилки залишаються підсвіченими після Backspace, повторного відкриття та переходів між фрагментами. Стирання прибирає лише помилки видалених символів.
- Скасування імпорту й очищення частково записаних книг. Web Locks захищають активні імпорти в інших вкладках від очищення.

## Зберігання та великі книги

Текст книги зберігається в IndexedDB фрагментами до 1 200 UTF-16 одиниць. Web Worker потоково читає XML і розпаковує по одному текстовому розділу EPUB. Записи передаються до IndexedDB пакетами з очікуванням завершення, тому імпорт не накопичує весь текст у пам’яті. На екрані — один фрагмент, наступний попередньо завантажується. Навіть один величезний абзац розбивається на фрагменти. Зміст показується сторінками по 100 розділів.

Після кожного натискання невеликий журнал позиції синхронно записується в localStorage, а зведений запис — у IndexedDB із затримкою 300 мс. Це дозволяє відновити позицію після негайного закриття вкладки. Сам текст книги ніколи не записується в localStorage.

Розмір обмежений доступною квотою браузера/диска. Книги з DRM або сканами без тексту не підтримуються. Пошкоджені чи нестандартні FB2/EPUB можуть вимагати виправлення файла. Очищення даних сайту видаляє бібліотеку; налаштування містять запит постійного сховища й резервну копію прогресу. Файл прогресу не містить самих книг. Збереження не гарантує останнє натискання при відмові диска, аварії ОС або забороненому сховищі.

## Перевірки

```powershell
npm.cmd test
npm.cmd run test:browser
npm.cmd run build
```

Браузерні тести потребують запущеного `npm.cmd run dev`. Використовується вже встановлений Brave; альтернативний Chromium можна передати через `BROWSER_PATH`. Синтетичні книги й скриншоти створюються в ігнорованій папці `test-results`.

Результат 2026-10-21: 6 модульних перевірок та 17 наскрізних браузерних сценаріїв. FB2 113,5 МБ / 55,8 млн символів імпортувалася за ~9 с, великий однорозділовий EPUB із 67,4 МБ XHTML — за ~4,1 с. Подробиці та межі вимірювань — у [docs/verification.md](docs/verification.md).
